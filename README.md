# কথাখাতা (KothaKhata)

আয়-ব্যয়, ওয়ালেট, বাজেট, সঞ্চয়, পাবো-দিবো, কাজের তালিকা, নোট, রিমাইন্ডার আর
অ্যালার্ম — এক অ্যাপে। বাংলায় মুখে বলে খরচ লেখা যায় (“আজ বাজারে ৫০০ টাকা খরচ”)।

## চালানো (Windows)

```
pwsh -NoProfile -File "F:\Personal App\dinsathi\serve.ps1"
```

তারপর Chrome বা Edge-এ খুলুন: http://localhost:5173
ঠিকানা বারের ডান পাশে **Install** আইকন চাপলে কম্পিউটারে অ্যাপের মতো বসে যাবে।

ভয়েস পার্সারের টেস্ট: http://localhost:5173/tests.html

## ভাষা ও ফন্ট

- বাংলা লেখা **কালপুরুষ** ফন্টে (SIL OFL 1.0, github.com/potasiyam/Kalpurush, jsDelivr থেকে নির্দিষ্ট commit-এ পিন করা), ইংরেজি লেখা Inter ফন্টে।
- উপরের **EN / বাং** বাটন বা সেটিংস → অ্যাপের ভাষা দিয়ে পুরো অ্যাপ English/বাংলায় বদলায় (তারিখ, সংখ্যা, মাসের নামসহ)। ভাষা বদলালে ভয়েসের ভাষাও সাথে বদলায়, সেটিংস থেকে আলাদা করে ঠিক করা যায়।
- অনুবাদ থাকে `js/i18n.js`-এ। নতুন বাংলা লেখা যোগ করলে ওখানে তার English যোগ করুন।

## যা জানা দরকার

- সব তথ্য শুধু এই ব্রাউজারে (IndexedDB) থাকে, কোনো সার্ভারে যায় না।
  সেটিংস → **ব্যাকআপ নামান** দিয়ে মাঝে মাঝে ফাইল রেখে দিন।
- ভয়েস টাইপিং Chrome/Edge-এ চলে, ইন্টারনেট লাগে, প্রথমবার মাইকের অনুমতি দিতে হয়।
- অ্যালার্ম ও রিমাইন্ডার বাজে যখন অ্যাপ (ট্যাব বা ইনস্টল করা উইন্ডো) খোলা থাকে।
  অ্যাপ বন্ধ থাকলে মিস হওয়া অ্যালার্ম নোটিফিকেশনে লেখা থাকে।
- AI দিয়ে গোছানো ঐচ্ছিক: সেটিংসে নিজের Google Gemini API key দিন (শুধু ডিভাইসে থাকে)।
- ফোনে চালাতে হলে অ্যাপটা কোনো HTTPS হোস্টিং-এ রাখতে হবে (পরের ধাপ: deploy)।

## ফাইল

| ফাইল | কাজ |
| --- | --- |
| `index.html`, `manifest.webmanifest`, `sw.js` | অ্যাপ, ইনস্টল আর অফলাইন |
| `css/app.css` | ডিজাইন টোকেন ও কম্পোনেন্ট (লাইট/ডার্ক) |
| `js/db.js` | লোকাল ডেটাবেস (IndexedDB) |
| `js/model.js` | হিসাবের লজিক: মোট, বাজেট, ওয়ালেট, পাবো-দিবো, নিয়মিত এন্ট্রি |
| `js/voice.js` | ভয়েস টাইপিং + বাংলা টাকা/ক্যাটাগরি বোঝা + AI গোছানো |
| `js/reminders.js` | রিমাইন্ডার ও অ্যালার্ম |
| `js/screens/*.js` | সব স্ক্রিন |
